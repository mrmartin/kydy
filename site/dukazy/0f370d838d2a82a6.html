405B.
406cestujícímu se vrátí částka podle vzorce:
407X = C – S – M – V
408X - vrácená částka cestujícímu
409C - cena vraceného kupónu
410S - u měsíčních dokladů S = C x P x 0,045, nejméně však 100 Kč
411u čtvrtletních dokladů S = C x P x 0,015, nejméně však 100 Kč
412u ročních dokladů: S = C x P x 0,004, nejméně však 100 Kč
413P - počet dosud uplynulých dnů platnosti dokladu včetně prvního dne platnosti dokladu a dne, kdy oprávněný žádost podal. K uplynulým dnům platnosti se u zlevněných dokladů přičítají všechny dny, kdy jízdenka měla speciální status (kvůli zkrácení platnosti) a také dny, pro které nebyl doložen slevový nárok.

415V - od vracené částky se odečítá cena uplatněných voucherů
